Privasi

SlopGuard mengirimkan teks halaman yang dianalisis ke provider LLM pilihan Anda (Gemini API) untuk mendapatkan skor AI-probability.

Tidak ada data yang dikirim ke server SlopGuard. Komunikasi hanya terjadi langsung antara ekstensi dan provider LLM Anda (BYOK).

API key disimpan secara lokal di browser Anda dan tidak pernah ditransmisikan ke pihak lain selain provider yang dikonfigurasi.
